# 刘琪的个人主页

https://fromostart.github.io/

基于 [PRISM](https://github.com/xyjoey/PRISM) 的个人主页，保留原版布局、配色、导航和主题切换，替换为刘琪的教育、竞赛、研究、组织经历与 DebateForTruth 内容。

网站包含关于我、研究与项目、竞赛、经历、随笔、简历六个页面。

此仓库存放 Next.js 静态导出文件，由 GitHub Pages 发布。源码在用户工作区 personal-homepage/prism；修改 content/ 和 content_zh/ 后运行 npm run build，再发布 out/ 中的文件。
