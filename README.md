# 刘琪的个人主页

原创桌面 Bento Grid 个人主页，内容包括成长、竞赛与研究、个人特质，以及 DebateForTruth。

https://fromostart.github.io/

## 结构与编辑

index.html 包含页面样式、交互与图片，可直接打开。按 E 开启文字编辑，Esc 退出；浏览器中的修改只保存在本地，需要导出 HTML 后提交到仓库才会更新线上内容。浏览器可能要求允许下载。

电脑版采用不等宽卡片：左侧身份大卡，右侧 About、技能、最新文章、联系，底部代表作长卡。不提供独立手机版。
